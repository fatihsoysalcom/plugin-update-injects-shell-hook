# Plugin Update Injects Shell Hook

This example demonstrates how a seemingly innocuous plugin update can introduce a 'shell hook' into an application's configuration. The main AI application then unknowingly executes this hidden command during its startup process. It highlights the security risk where external dependencies can silently alter system behavior.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
